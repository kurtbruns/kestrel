# Upgrade to a new release (moved)

This page moved to [upgrade.md](upgrade.md), beside this file: `node_modules/@kurtbruns/kestrel/docs/guides/upgrade.md` in an instance. Docs pages no longer carry a number in their file names.

If you reached this page partway through an upgrade, because your upgrade skill reads the guide by its old name, read `upgrade.md` now and carry on in it from the step after the install, exactly as you would have here. Nothing else about the upgrade changes. This release's `npm run check-context` brings in the upgrade skill that reads the new name.

This file is kept only so an upgrade to the release that renamed the pages doesn't stop, and is removed in the release after it.
