# Go live

At this point, your instance should be deployed, verified, and out of the SES sandbox, so it can send to anyone. From here, you either start publishing, or extend your setup with the guides below.

## Start publishing

The rest happens in the editor, at `https://newsletter.example.com/dashboard/`. The Publishing docs walk through it in the order of the dashboard's checklist, starting with [Name your publication](../publishing/03-name-your-publication.md). If someone else writes the newsletter, send them that link.

## Extend your setup

Each of these guides stands on its own. Pick the ones you want.

- [Connect Claude to the API](../guides/01-connect-claude.md), so Claude can draft, proofread, and schedule posts through the same API the editor uses.
- [Notifications through Cloudflare's email](../guides/03-notifications.md), so you hear about problems even when your email provider has stopped sending.
- [Rate-limit the subscribe form](../guides/05-rate-limit.md), before you share your subscribe link widely.
- [As your list grows](../guides/09-as-your-list-grows.md), from about 5,000 subscribers.
- [Upgrade to a new release](../guides/07-upgrade.md), when one comes out.
