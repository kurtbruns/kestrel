# Get notified

Kestrel emails you when a send finishes or needs you, so a problem reaches you without your watching the dashboard. Under **Settings → Notifications**, type your address under **Send notifications to** and choose **Add inbox**, which saves it right away. Then choose **Send a test notification**, which goes to every address listed.

**If someone else runs your Kestrel instance, add their address too,** so a problem that needs them reaches both of you.

**Until AWS grants production access, Amazon SES mails only addresses verified in SES,** notifications included. Use a verified address until then, or the test won't arrive. [Request production access](../get-started/production-access.md) covers the grant.

The dashboard's **Get notified** step is checked off once an address is saved and the last notification arrived. If it didn't arrive, **Last notification**, on the same page, says why, and the dashboard says so above its steps. [Notifications](troubleshooting.md#notifications) lists what Kestrel emails you about.
