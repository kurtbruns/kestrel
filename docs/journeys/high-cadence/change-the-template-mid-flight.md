# High-cadence: change the template mid-flight

**Archetype:** [High-cadence publisher](README.md) · Sketch

## Steps

1. A post is already scheduled: frozen render, soft-locked.
2. Edit the email template or the publication identity in Settings.
3. Confirm the "in use by N scheduled posts" prompt and acknowledge the remake.
4. Verify the scheduled post's frozen render now reflects the new template, without the publisher touching the post itself.
