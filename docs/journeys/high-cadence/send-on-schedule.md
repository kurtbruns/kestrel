# High-cadence: send a post on schedule

**Archetype:** [High-cadence publisher](README.md) · Sketch

## Steps

1. Reuse the existing template for the next post. There is no per-post template today, so this really means "the template already matches."
2. Write the post, preview it, and schedule it for the usual send time.
3. Watch the send drain in the active-send view; confirm dispatch completes.
4. After it sends, check the record's delivery outcomes (delivered, bounced, complained, unsent) against the usual baseline.
5. Investigate anything above baseline: open Subscribers and check for new suppressions.
