# Solo: onboarding

**Archetype:** [Solo publisher](README.md) · Sketch

## Steps

1. Follow the setup guide (`docs/setup/`) to deploy a fresh instance.
2. Open the dashboard for the first time: empty subscriber list, default template, no sent history.
3. Set the publication identity (name, tagline, logo) in Settings.
4. Subscribe themself as a test, confirm through the email link, and watch the subscriber count move to 1.
5. Write and send a first post ([write and send a post](write-and-send.md)), watching for anything that reads as broken only because everything is empty or default the first time through.
