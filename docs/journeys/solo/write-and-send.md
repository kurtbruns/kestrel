# Solo: write and send a post

**Archetype:** [Solo publisher](README.md) · Sketch

## Steps

1. Drafts → New post.
2. Write the subject and Markdown body, and watch autosave settle.
3. Switch to Preview and spot-check the formatting.
4. Send a test email to their own inbox and check it in a real client.
5. Schedule it; the review window opens.
6. Optionally cancel or reschedule while the window is still open.
7. Once the fire time passes, check the Sent page and confirm the delivered count.
